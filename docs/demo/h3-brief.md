# MiniMax H3 制作说明（2 分钟短版）

配套 [`video-kit.md`](video-kit.md) §6。这份文件回答一个问题：**把成片交给 MiniMax H3 生成时，H3 该做哪几段、怎么写提示词、怎么验收。**

H3 是全模态视频生成模型（2026-07-31 发布并开源）：单段 4–15 秒（整数秒）、768P 或 2K、24 fps、原生立体声；模式有文生视频（T2VA）、首帧（I2VA）、首尾帧（FL2VA）、尾帧（L2VA）和全能参考（最多 9 图 + 3 段视频 + 3 段音频，合计 12 个文件）；提示词上限 7000 字符；每个上传文件都要在提示词里声明角色（`@image1`、`@video1`）。官方强调它在指令遵循、**文字与品牌信息呈现**、V2V 运动迁移上表现好。官方文档：<https://platform.minimaxi.com/docs/guides/video-generation>。

---

## 0. 先说结论：H3 做感受层，不做事实层

这条视频的说服力全在**画面上的字是真的**：`AP_Pick_GetPickOrderRows`、`需要更多证据 · 80%`、`T12288: 0`。生成模型再强，也不能保证 210 个节点的名字一个不错。所以分层：

| 层 | 内容 | 来源 |
|---|---|---|
| 事实层 | 镜 1–5 的全部 UI 画面：全图、溯源、回放流转、调查、状态栏 | **真实录屏**（[`video-kit.md`](video-kit.md) §6.5 的 Clip A/B/C） |
| 感受层 | 片头字卡的呼吸、片尾、两处转场、可选 B-roll | **H3 生成** |
| 实验层 | 镜 3 的「路径逐层点亮」用首尾帧插值再生成一版 | H3 FL2VA；**验收不过就用录屏** |

「流转」本身产品已经会演：图标题栏 **▶ 回放流转**（深链 `&replay=1`）播出约 10 秒的真实动画——路径变暗、调用沿执行路径逐节点向下、每条边跑一个光点、取值沿血缘逐层向上、最后 `T12288: 0` 落进字段。**录屏拿到的就是最专业的那一版**，H3 的任务是让它前后的 20 秒同样讲究。

## 1. 流水线

```
① 录屏（Chrome 应用模式 1920×1080，Clip A / B / C）
② H3 生成：H3-01 片头 · H3-02 转场 · H3-04 片尾 ·（实验）H3-03 首尾帧插值 ·（可选）H3-05 B-roll
③ 剪辑合成：按 §6.1 时间轴排；H3 段全部静音；旁白 / 字幕 / 叠字 / BGM 在剪辑里加
④ 导出 1080p（或 2K；H3 段本身可出 2K，录屏段 1080p 上采样即可）
```

H3 每段都带原生音频，但这条片子的声音只有一个来源：旁白。**所有 H3 段静音使用**，提示词里仍写清「无对白、无旁白、无音乐」，减少模型往画面里加嘴型和字幕的冲动。

## 4. 提示词

按官方 Base 格式写：**首帧对齐行 →（按时间顺序的）一体化音画描述 → 整体声景 → 非叙事音乐**。相机运动写具体动作，不写「电影感」这类空词；要连续镜头就明说「单一连续镜头，无剪切」——H3 默认会切镜。

### H3-01 片头（I2VA，5 s）

```
@image1 是视频 0.00 秒的首帧，属于 [Shot 1]。画面是一张 1920×1080 的深色字卡：底色 #0a0d12，铺满 24 像素间距的极淡白色圆点阵；左上角是一个带青色（#3fc1e8）细边框的方块标志，里面是等宽字体的字母 X，右侧写着「MES X-Ray」和一行小字；画面中部偏上是一行大字「页面上只是一个 0。」，其中数字 0 为青色并带柔和光晕；左下角一行等宽小字。所有文字的字形、位置、大小、颜色在整段视频里保持完全不变。

[Shot 1] 单一连续镜头，无剪切。0.0–5.0 秒：相机以极慢的速度向那个青色的 0 推近（整段推进不超过画面的 3%）。点阵保持静止。青色 0 的光晕做一次缓慢的呼吸：1.5 秒时最亮，3.5 秒时回到初始亮度。4.2–5.0 秒，从 0 的中心向外扩散出一圈极细的青色光环，扩散到大约三倍字高时完全透明。没有任何人物、手、鼠标指针，不出现新的文字或图形，不改变任何已有文字。

整体声景：接近无声的电子环境低鸣，非常轻；无对白、无旁白、无字幕。
非叙事音乐：无。
```

### H3-02 转场「X 光扫描」（T2VA，4 s）

```
主体与场景：一块 1920×1080 的深色画面，底色 #0a0d12，铺满 24 像素间距、亮度极低的白色圆点阵，像一张空白的图纸。风格：极简的深色软件界面动效，扁平，无光斑镜头效果，无颗粒。

[Shot 1] 单一连续镜头，固定机位，无剪切。0.0–0.4 秒：画面静止。0.4–3.2 秒：一条竖直的、约 160 像素宽的青色（#3fc1e8）光带从画面左边缘匀速扫到右边缘，光带右边缘最亮、向左渐隐；光带经过之处，点阵里的圆点被短暂点亮成青色，随后在 0.5 秒内回到原来的暗淡。3.2–4.0 秒：光带离开画面，一切回到静止。没有文字、没有图标、没有节点或线条、没有人物。

整体声景：一声很轻、很短的电子扫描音随光带经过，之后是近乎无声的低鸣；无对白、无音乐。
非叙事音乐：无。
```

### H3-03 首尾帧插值实验（FL2VA，10 s）

```
@image1 是视频 0.00 秒的首帧，@image2 是视频 10.00 秒的尾帧，两张都是同一个深色软件界面（MES X-Ray）的截图：左侧是响应树，中间是节点图，右侧是检视器，底部是状态栏。两帧的界面布局、每一个节点的位置和大小、每一个字的字形和内容都**完全相同**；唯一的区别是中间图里那条追踪路径的亮度：首帧里路径上的节点是暗的、连线是灰的、节点上没有取值标签；尾帧里这些节点变亮、连线变成青色（#3fc1e8）虚线、部分节点上出现了青色的取值小标签（例如「T12288: 0」）。

[Shot 1] 单一连续镜头，固定机位，画面不缩放、不平移，无剪切。界面上除追踪路径以外的一切（左右两栏、顶栏、底栏、暗淡的背景节点、所有文字）从头到尾保持与两张图一致，不出现任何新的文字、图形、人物或指针。路径的点亮**按顺序**发生：0.5–4.0 秒，沿图右侧那一列节点从最上面（Web VP - Pick Order Details）往下逐个点亮，每次点亮时该节点边框闪出一圈青色光并有一个青色小光点沿连线从上一个节点滑到它；4.0–4.5 秒静止；4.5–9.5 秒，沿图中部和左侧的血缘节点从最下面一层往上逐层点亮，同样有光点沿连线向上滑动，被点亮的节点上出现尾帧里对应的取值小标签；9.5–10.0 秒，最顶部的 availableQuantity 节点最后亮起，边框向外扩出一圈青色光环后停在尾帧的状态。所有连线在点亮后保持青色虚线。

整体声景：近乎无声的电子低鸣，每次节点点亮时有一声极轻的、清脆的点击音；无对白、无音乐。
非叙事音乐：无。
```

验收见 §5。这条任务最难：模型只要改了一个节点名或多画一条线，就不能用。

### H3-04 片尾（I2VA，5 s）

```
@image1 是视频 0.00 秒的首帧，属于 [Shot 1]。画面是一张 1920×1080 的深色字卡：底色 #0a0d12，铺满 24 像素间距的极淡白色圆点阵；画面中部左侧是带青色（#3fc1e8）细边框的方块标志（里面是等宽字体的 X）和大字「MES X-Ray」，下面一行是「扫描器造证据 · 运行时绑取值 · AI 只许引用证据」，再下面一行等宽小字是仓库地址；左下角一行等宽小字。所有文字的字形、位置、大小、颜色在整段视频里保持完全不变。

[Shot 1] 单一连续镜头，固定机位，无剪切。0.0–5.0 秒：整幅画面静止；只有方块标志边框的青色光晕做一次缓慢的呼吸（2.5 秒时最亮，5.0 秒回到初始），以及点阵里随机约 1% 的圆点在 1.0–4.0 秒之间以极低的亮度依次闪烁一次后熄灭。没有人物、指针、新文字或新图形。

整体声景：近乎无声的电子低鸣；无对白、无旁白、无音乐。
非叙事音乐：无。
```

### H3-05 可选 B-roll「图醒过来」（全能参考，8 s）

```
参考文件：@video1 是一段软件界面录屏，画面里一条节点路径先暗下去、再从上往下和从下往上逐个点亮，每次点亮有青色光点沿连线滑动——请只参考它的**运动节奏与方向**（逐个点亮的顺序、光点沿线滑动的速度），不要复制它的界面元素。@image1 是同一软件的架构全图截图，请参考它的**构图与配色**（深色底 #0a0d12、青色 #3fc1e8 的高亮、灰白的节点框、自下而上的层次），不要复制其中的文字。

目标视频：一张抽象化的节点图——约 40 个无文字的圆角矩形节点排成 6–8 层，用细线相连，初始全部暗淡。风格：极简深色软件界面动效，扁平，无镜头光斑。

[Shot 1] 单一连续镜头，固定机位，无剪切。0.0–1.0 秒静止。1.0–4.0 秒：最上层的一个节点先亮起，随后沿右侧一列向下逐个点亮，每次有一个青色光点沿连线滑到下一个节点。4.0–7.5 秒：从最底层开始逐层向上点亮，光点沿多条连线同时向上汇聚。7.5–8.0 秒：最顶部节点亮起并向外扩出一圈青色光环。全程无文字、无人物、无指针。

整体声景：近乎无声的电子低鸣，节点点亮时极轻的点击音；无对白、无音乐。
非叙事音乐：无。
```

## 5. 验收标准

每段生成物先在 100% 尺寸下逐帧看一遍，再决定用不用。

| 检查项 | H3-01 / 04 字卡 | H3-02 转场 | H3-03 插值 | H3-05 B-roll |
|---|---|---|---|---|
| 文字与首帧逐字一致（字形、位置、颜色） | 必须 | 不得出现文字 | **必须**（含状态栏数字、取值标签） | 不得出现文字 |
| 没有多出来的图形 / 节点 / 线 / 指针 / 人物 | 必须 | 必须 | **必须** | 允许抽象节点，不许文字 |
| 单一连续镜头，无剪切、无缩放漂移 | 必须 | 必须 | 必须（画面不能平移） | 必须 |
| 颜色在配色板内（青色不发紫、不发绿） | 必须 | 必须 | 必须 | 必须 |
| 点亮顺序：先执行路径向下，再血缘向上，字段最后 | — | — | 必须 | 尽量 |
| 时长 / 24 fps / 16:9 | 必须 | 必须 | 必须 | 必须 |

**重生成策略**：同一任务最多重试 3 次（微调提示词，不换模式）；三次不过就放弃该任务，用录屏或静帧慢推（Ken Burns）顶上。H3-03 不过是正常结果，不是失败——录屏本来就是主方案。

**留档**：每次生成记下 task_id、提示词版本、seed（如有）、结论；成片用到的那一版提示词复制到剪辑工程目录。

## 6. 合成顺序与音频

按 [`video-kit.md`](video-kit.md) §6.1 的时间轴：

```
0:00  H3-01 前 3 秒（片头）
0:03  Clip A（全图 → 点字段 → 光带 → 展开）        ← 镜 1–2 连拍
0:24  H3-02 0.7 秒叠化                              ← 可选
0:52  Clip B（&replay=1 回放 → 0 落定 → 划过三个数） ← 或 H3-03（验收通过时）
1:12  Clip C（调查 → 点证据芯片）+ 1:42 对照卡 2 秒
1:50  Clip A 起始帧放大状态栏                        ← 或 H3-02 0.7 秒叠化后切
1:55  H3-04（片尾）
```

- H3 段全部**静音**；旁白按 §6.2 录制，1.3–1.5 倍；字幕照旁白打；BGM 可无，有则 ≤ -24 dB。
- 叠字 4 条（§6.3）在剪辑里加，不要让 H3 生成任何叠字。
- 导出：1080p H.264 高码率即可；若要 2K，H3 段本身出 2K，录屏段上采样。

## 7. API 调用要点

Hailuo 网页版（<https://hailuoai.video/tools/minimax-h3>）可以直接选模式、拖入参考文件、填提示词，最省事。走 API 时：

```json
{
  "model": "MiniMax-H3",
  "content": [
    { "type": "text", "text": "<上面的提示词>" }
  ],
  "resolution": "2K",
  "duration": 5,
  "ratio": "16:9"
}
```

`POST /v2/video_generation` 是异步接口，返回 `task_id`，再轮询 `GET /v2/query/video_generation/{task_id}` 取视频地址。图片输入以 `image_url` 项加入 `content`；首/尾帧、全能参考的字段名和角色标记以官方 API 文档为准（<https://platform.minimaxi.com/docs/api-reference/video-generation-v2-create.md>），不要按记忆猜字段。素材推荐用 URL 传入；单个图片 ≤ 30 MB、视频 ≤ 50 MB。

密钥只放在那台生成用的电脑上，不进仓库、不进剪辑工程目录。
