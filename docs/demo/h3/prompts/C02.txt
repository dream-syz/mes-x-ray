【统一风格】这是一款深色工程软件「MES X-Ray」的界面动效：扁平、克制、极简；没有镜头光斑、颗粒、景深虚化、水印，没有任何人物、手、鼠标指针。配色以首尾帧为准：底色 #0a0d12 带 24 像素点阵，面板色 #0f131a，强调色青色 #3fc1e8。
文字规则：所有文字以首尾帧为准，字形、位置、大小、颜色保持不变；不得新增任何首尾帧上没有的文字、图标、节点或连线；灰色短横条是界面里的占位文字，整段保持为横条，不要把它们变成文字。
运镜：单一连续镜头，固定机位，无剪切、无抖动、无转场。最后 0.5 秒的画面必须与尾帧完全一致。24 fps，16:9。

首帧图是视频 0.00 秒的画面，尾帧图是视频第 11.00 秒的画面，二者属于同一个 [Shot 1]。两张图的界面布局和节点位置完全相同。区别：首帧里所有节点都是未点亮的深灰色，右侧面板是横条列表；尾帧里一条路径被点亮为青色（节点边框变青、底色变成深青灰、连线变成青色虚线），其余节点和连线退暗到约 30%，函数节点下方多了一枚青色小胶囊「内部 +12」，右侧面板变成 8 枚由小箭头串起的青色胶囊。

[Shot 1]
0.0–1.0 秒：静止在首帧。
1.0–1.8 秒：左上方的节点「availableQuantity」中心向外扩散一圈青色细光环，表示被点击（没有鼠标指针）。
1.8–2.8 秒：一条约 160 像素宽的青色扫描光带从画布左边缘掠到右边缘一次。
2.8–7.5 秒：与路径无关的节点和连线一起退暗到约 30%。同时两列自上而下点亮，每个节点相隔约 0.4 秒，被点亮的节点边框变青、底色变深青灰，节点之间的连线变成青色虚线：右侧一列是 页面 → API → 服务 → 服务 → 服务 → 存储过程 → 左边相邻的存储过程 → 函数；左侧一列是 availableQuantity → 属性 → 结果列 → 求和 → CASE；CASE 点亮后，它左边的「WMS_Enabled」、它到右下方函数节点的斜向虚线、它到底部「表」节点的竖向虚线一起点亮。
7.5–9.0 秒：函数节点下方浮现青色小胶囊「内部 +12」（淡入并轻微上移）。
9.0–10.5 秒：右侧面板里的横条列表整体淡出，8 枚由小箭头串起的青色胶囊自上而下依次淡入。
10.5–11.0 秒：静止在尾帧。

画外旁白：中性、沉稳、语速稍快的中文女声，无画面内说话者，不生成字幕：「一次点击。右边这条是执行路径：从页面一路走到存储过程，最后进到一个函数。左边是血缘：字段、属性、求和，再往上是一个 CASE。」
整体声景：近乎无声的电子低鸣；点击处一声极轻的点击音；光带经过时一声很轻的扫描音；每个节点点亮时极轻的滴答声。
非叙事音乐：无。
