【统一风格】这是一款深色工程软件「MES X-Ray」的界面动效：扁平、克制、极简；没有镜头光斑、颗粒、景深虚化、水印，没有任何人物、手、鼠标指针。配色以首尾帧为准：底色 #0a0d12 带 24 像素点阵，面板色 #0f131a，强调色青色 #3fc1e8。
文字规则：所有文字以首尾帧为准，字形、位置、大小、颜色保持不变；不得新增任何首尾帧上没有的文字、图标、节点或连线；灰色短横条是界面里的占位文字，整段保持为横条。
运镜：单一连续镜头，固定机位，无剪切、无抖动、无转场。最后 0.5 秒的画面必须与尾帧完全一致。24 fps，16:9。

首帧图是视频 0.00 秒的画面，尾帧图是视频第 5.00 秒的画面，二者属于同一个 [Shot 1]。两帧布局完全相同。首帧里整条路径是暗的（灰边框、灰线）。尾帧里右侧那条执行路径的 8 个节点已被点亮为青色：页面 → API → 服务 → 服务 → 服务 → 存储过程 → 左边相邻的存储过程 → 函数，它们之间的连线是青色虚线，最后的函数节点带更亮的青色光晕；左侧那列血缘节点仍然是暗的；右侧面板的 8 枚胶囊变成青色。
